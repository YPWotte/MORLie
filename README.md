# Model order reduction via Lie groups

Contains MATLAB code for examples corresponding to our [article](https://arxiv.org/abs/2511.03520).

The repository also features:
- auxilliary functions for exponential maps on SE(3) and Aff(3), logarithmic maps, derivative of exponential map
- auxilliary functions for Levenberg-Marquardt on matrix Lie groups and SE(3) specifically
- an experimental library that generates matrix Lie groups from their Lie algebra, using Cayley-Hamilton to compute exponential, logarithmic and derivative of exponential map from structure coefficients
